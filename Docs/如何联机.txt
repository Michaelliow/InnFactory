InnFactory 客栈经营 + 自动化 —— 原型测试版

【运行】
解压后双击 InnFactory.exe（窗口模式，可拖动调整大小）。不需要安装。

【操作】
WASD 移动    E 交互（播种 / 浇水 / 收获 / 放食材 / 取菜 / 上菜）
F 灶台开火   G 灶台设定自动菜谱    Q 切换手上拿的东西（也可以点下面的背包格子）
1 / 2 / 3    去 菜园 / 厨房 / 饭厅
B 建造（左键放置，R 旋转，X 拆除，右键取消）
K 菜谱   H 招募员工   P 种子商店   N 联机   空格 暂停   T 加速   滚轮 缩放

新手流程：P 买种子 → 1 去菜园，选中种子对着耕地按 E 播种，再按 E 浇水 → 成熟后 E 收获
→ 2 去厨房，选中食材对着灶台按 E 放入，按 F 开火（同样的食材换灶台会做出不同的菜，做错是黑暗料理）
→ 3 去饭厅，对着坐着的客人按 E 上菜，客人吃完去柜台结账。

【联机：最多 5 人一起经营同一家客栈】
金币、名望、建筑、员工、菜谱大家共享；背包各自的。

开房间的人（主机）：
  1. 按 N 打开联机面板，填名字，点“开房间”。
  2. 第一次会弹出 Windows 防火墙提示，请点“允许”（勾选“专用网络”）。
  3. 面板上会显示房间地址（IP:端口），发给朋友。

加入的人：
  - 同一个局域网 / 同一个 WiFi：按 N，房间会自动出现在列表里，点“加入”。
  - 不在同一个网络：
      方法 A（推荐）：大家装同一个虚拟局域网工具（如 ZeroTier、Radmin VPN、蒲公英等），
               进同一个网络后，填主机在虚拟网络里的 IP 加入。
      方法 B：主机在路由器上把 TCP 7790 端口映射到自己的电脑，朋友填主机的公网 IP 加入。

注意：
  - 客栈运行在主机上，主机关掉游戏所有人都会断开。
  - 原型还没有存档，退出游戏后进度不保留。
  - 满 5 人后再加入会提示“房间已满”。
